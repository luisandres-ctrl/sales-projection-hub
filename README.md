# Sales Projection Hub

Esto es un muckup tonto con html y bootstrap (ultima version por CDN) no tiene que estar conectado a internet o ninguna base de datos solo usará datos tontos y de be estar preparada para los principales dispositivos IOS (Tablets, celulares y laptops), de una aplicación con la intención principal de ayudar a vendedores (grandes, medianos y chicos) a realizar una proyección de costos de un producto determinado
la app se llama "Sales Forcaster by Molten Logistics"
queremos hacer una interfaz amigable para el usuario donde pueda fijar productos seleccionados, ver graficas de precos historicos y hacer proyecciones a futuro (corto, medano y largo plazo)
Estas son las funcionalidades específicas que necesito en prototipo:
inicio de sesión, registro de usuario(permitir usar google o mail), lista de proyecciones guardadas, búsqueda libre de producto a querer proyectar.
si necesitas inspiracion para la ux/ui puedes obtenerla de  www.moltenlogistics.com
